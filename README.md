# One Emoji, One Dream Vacation

Exactly one emoji for the dream vacation — a desert island, a postcard at a glance.

> 🏝

`main.py` (Python 3.13, stdlib only) writes that emoji to `/output/entry.txt`. Deterministic: the same text on every run.
